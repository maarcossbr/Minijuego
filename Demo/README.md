# Demo ejecutable

Coloca en esta carpeta la build final comprimida como:

`Minijuego.zip`

El ZIP debe incluir todos los archivos generados por Unity, no solo el archivo `.exe`.

Ejemplo:

```
Demo/
└── Minijuego.zip
    ├── Minijuego.exe
    ├── Minijuego_Data/
    ├── UnityPlayer.dll
    └── ...
```
